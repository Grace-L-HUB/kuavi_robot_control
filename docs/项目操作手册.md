# Kuavi 语音视觉抓取系统 — 项目操作手册

本文档面向**现场联调与日常操作**，说明从数据采集到机械臂抓取的完整流程。系统架构与模块说明见根目录 [readme.md](../readme.md)。

---

## 1. 系统角色与职责

| 节点 | 硬件/环境 | 操作者需完成的工作 |
|------|-----------|-------------------|
| **上位机** | 轮臂机器人工控机或开发 PC | 同步采集 RGB-D 图像、相机内参、语音录音 |
| **Atlas 200I DK A2** | 昇腾 NPU 开发板 | 运行语音 + 视觉流水线，输出 `grasp_target.json` |
| **下位机** | Kuavo ROS 机器人 | 读取 JSON，执行机械臂 IK 与夹爪抓取 |

三机之间通过 **U 盘** 或 **scp** 交换 `instance/` 数据包与 `grasp_target.json`。

```
上位机采集 → Atlas 推理 → 下位机抓取
   instance/     grasp_target.json     grasp_from_offline_vision.py
```

## 2. 环境要求

### 2.1 Atlas 200I DK A2

| 项目 | 要求 |
|------|------|
| 系统 | Ubuntu 20.04 aarch64 |
| NPU 软件 | CANN 6.0+（`source /usr/local/Ascend/ascend-toolkit/set_env.sh`） |
| Python | 3.9 虚拟环境 `~/kuavi` |
| 模型文件 | `ascend_models/yolov8n.om`、`ascend_models/whisper_encoder.om` |
| 额外依赖 | `ffmpeg`（m4a 转 wav） |

### 2.2 下位机（Kuavo ROS）

| 项目 | 要求 |
|------|------|
| ROS | Noetic |
| 工作空间 | `kuavo-ros-opensource` 或 `kuavo-ros-control` 已编译 |
| Python 包 | `kuavo_sdk`、`motion_capture_ik` 可正常 import |
| 接口 | IK 服务、`/kuavo_arm_traj` 或 `/kuavo_arm_target_poses`、夹爪话题 |

### 2.3 上位机

| 项目 | 要求 |
|------|------|
| 传感器 | RGB-D 相机（与机器人头顶安装一致） |
| 录音 | 麦克风，输出 m4a/wav |
| 数据格式 | 见下文「数据文件规范」 |

## 3. 首次部署检查

### 3.1 Atlas 环境自检

```bash
cd ~/kuavi_robot_control
bash scripts/setup_atlas_npu.sh
```

每次新开终端运行流水线前，必须执行：

```bash
source scripts/activate_kuavi_atlas.sh
```

成功标志：终端输出 `import acl OK` 且 `soc= Ascend310B4`。

### 3.2 下位机环境自检

```bash
cd /path/to/kuavo-ros-opensource/scripts
export KUAVO_WS_SETUP=/home/lab/kuavo-ros-opensource/devel/setup.bash
bash run_grasp.sh --dry-coords --hand left
```

成功标志：打印各路径点坐标，机械臂**不动作**。

## 4. 标准操作流程（端到端）

### 步骤 0：启动上下位机

参考kuavo机器人官方网站文档，启动上下位机，通过手机热点与PC连接，实现连接。

下位机：
终端1
```bash
source devel/setup.bash
roslaunch humanoid_controllers load_kuavo_real_half_up_body.launch
```

终端2
```bash
cd kuavo-ros-opensource  # 进入下位机工作空间
sudo su
source devel/setup.bash
roslaunch motion_capture_ik ik_node.launch 
```

上位机
```bash
cd ~/kuavo_ros_application
source /opt/ros/noetic/setup.bash
source ~/kuavo_ros_application/devel/setup.bash 
```

### 步骤 1：上位机采集数据

在目标场景**同一时刻**采集以下文件，放入 `instance/` 目录：

| 文件 | 来源 / 说明 |
|------|-------------|
| `color_image.png` | RGB 彩色图 |
| `depth_image.png` | 对齐的深度图（16 bit 单通道） |
| `camera_info.txt` | `/camera/color/camera_info` 导出 |
| `camera_info1.txt` | `/camera/depth/camera_info` 导出 |
| `record*.m4a` | 语音指令，如「拿瓶子」 |

> **重要**：图像、深度、内参、语音必须来自**同一次观测**。时间不一致会导致检测位置与深度不匹配。

将整个 `instance/` 目录拷贝到 Atlas：

```bash
scp -r instance/ user@atlas-ip:~/kuavi_robot_control/instance/
```

### 步骤 2：Atlas 运行语音 + 视觉流水线

```bash
cd ~/kuavi_robot_control
source scripts/activate_kuavi_atlas.sh

python3 scripts/atlas_voice_grasp_pipeline.py \
  --asr-config config/asr_atlas_npu.yaml \
  --vision-config config/vision.yaml \
  --device npu \
  --audio instance/record5.m4a
```

流水线依次完成：

1. **ASR** — m4a → Whisper NPU encoder + CPU decode → 文本（如「拿瓶子」）
2. **NLU** — 规则语义解析 → `{"action":"fetch","target":"bottle",...}`
3. **YOLO** — NPU 检测目标 bbox，取抓取像素（水平中心 + 垂直 65% 偏下）
4. **坐标** — 深度采样 + 内参反投影 → `camera_coord_m`（相机 optical 系，单位米）

输出文件：

- `instance/grasp_target.json`
- `scripts/grasp_target.json`（副本，便于拷贝）

检查输出示例：

```json
{
  "voice_transcript": "拿瓶子",
  "voice_task": { "action": "fetch", "target": "bottle" },
  "yolo_backend": "npu",
  "camera_coord_m": [-0.213, 0.074, 0.582],
  "pixel_color": [178, 298],
  "depth_m": 0.582
}
```

将 `grasp_target.json` 与抓取脚本拷贝到下位机：

```bash
scp instance/grasp_target.json user@robot:/home/lab/kuavo-ros-opensource/scripts/
scp scripts/grasp_from_offline_vision.py user@robot:/home/lab/kuavo-ros-opensource/scripts/
```

### 步骤 3：下位机预览坐标（必做）

```bash
source /opt/ros/noetic/setup.bash
source /home/lab/kuavo-ros-opensource/devel/setup.bash
cd /home/lab/kuavo-ros-opensource/scripts

python3 grasp_from_offline_vision.py \
  --hand left \
  --dry-coords \
  --grasp-json grasp_target.json
```

确认日志中以下坐标合理：

- 抓取点 `GRASP_POS`
- 三段位姿路径点（左上方 → 正上方平移 → 正上方就位）
- 夹紧后上提、水平后撤放开点

### 步骤 4：下位机实机抓取

确认周围无障碍物、急停可用后执行：

```bash
python3 grasp_from_offline_vision.py \
  --hand left \
  --grasp-json grasp_target.json
```

或使用封装脚本（自动 source ROS 环境）：

```bash
export KUAVO_WS_SETUP=/home/lab/kuavo-ros-opensource/devel/setup.bash
bash run_grasp.sh --hand left --grasp-json grasp_target.json
```

## 5. 抓取动作流程说明

下位机 `grasp_from_offline_vision.py` 默认配置（`USE_THREE_STAGE_APPROACH = True`）执行以下动作序列：

| 阶段 | 动作 | 说明 |
|------|------|------|
| 1. 接近 | 左上方就位 | 高 + 左 + 后，从侧后方切入 |
| 2. 接近 | 平移至正上方 | 两段运动：高位平移 + 下降就位 |
| 3. 接近 | 垂直下降 | 到达抓取点 |
| 4. 抓取 | 闭合夹爪 | `left_claw` 夹紧 |
| 5. 展示 | 垂直上提 | 分两段上提至正上方，短暂停留 |
| 6. 安全放开 | 下放 → 水平后撤 → 松爪 | 避免原位松爪带倒物体 |
| 7. 收尾 | 上提 → 双臂回零 | `POST_GRASP_RELEASE_AND_HOME = True` |

若将 `USE_THREE_STAGE_APPROACH` 设为 `False`，则启用**安全悬停避障路径**：

```
正上方就位 → 安全悬停（X 轴后撤）→ 纯垂直下降 → 抓取
```

## 6. 命令行参数速查

### 6.1 Atlas 流水线 `atlas_voice_grasp_pipeline.py`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--audio` | `instance/record1.m4a` | 语音文件 |
| `--color` | `instance/color_image.png` | 彩色图 |
| `--depth` | `instance/depth_image.png` | 深度图 |
| `--camera-info-color` | `instance/camera_info.txt` | color 内参 |
| `--camera-info-depth` | `instance/camera_info1.txt` | depth 内参 |
| `--asr-config` | — | NPU 模式用 `config/asr_atlas_npu.yaml` |
| `--vision-config` | — | 默认 `config/vision.yaml` |
| `--device` | `auto` | `auto` / `npu` / `cpu` |
| `--text` | — | 跳过 ASR，直接指定中文指令 |
| `--vertical-ratio` | `0.65` | 抓取点在 bbox 内的垂直比例 |
| `--output` | `instance/grasp_target.json` | 输出路径 |

**调试示例**（跳过语音识别，直接测视觉）：

```bash
python3 scripts/atlas_voice_grasp_pipeline.py \
  --text "拿瓶子" \
  --device npu
```

### 6.2 下位机抓取 `grasp_from_offline_vision.py`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--hand` | `right` | 抓取手：`left` / `right` |
| `--grasp-json` | 同目录 `grasp_target.json` | 含 `camera_coord_m` 的 JSON |
| `--camera-coord X Y Z` | — | 覆盖 JSON，直接指定相机坐标 (m) |
| `--dry-coords` | — | 只打印坐标，不控制机械臂 |
| `--grasp-width` | `90` | 夹爪闭合宽度 |
| `--grasp-effort` | `1.5` | 夹爪力度 |
| `--skip-gripper` | — | 跳过夹爪动作（仅测手臂） |
| `--skip-arm-mode` | — | 跳过手臂模式切换 |

## 7. 参数调优指南

所有抓取相关参数位于 `scripts/grasp_from_offline_vision.py` 顶部 **「用户参数区」**。修改后务必先 `--dry-coords` 预览，再实机。

### 7.1 抓取偏位

| 参数 | 作用 | 调参方向 |
|------|------|----------|
| `LEFT_GRASP_X_BIAS` | 左手 X 方向微调 | 偏前/偏后 |
| `LEFT_GRASP_Y_BIAS` | 左手 Y 方向微调 | 偏左/偏右 |
| `LEFT_GRASP_Z_BIAS` | 左手 Z 方向微调 | 偏高/偏低 |
| `OFFSET_Z` | 全局抓取高度偏置 | 负值 = 抓更靠下 |
| `TEMP_X` / `TEMP_Y` | 官方偏置模板 | 左右手通用基准 |

### 7.2 接近路径 / IK 失败

| 参数 | 作用 | 调参方向 |
|------|------|----------|
| `APPROACH_ABOVE_CLEARANCE_M` | 正上方与抓取点的垂直间距 | IK 失败时适当减小 |
| `APPROACH_UPPER_LEFT_LATERAL_M` | 左上方横向外扩 | 增大可让路径更明显 |
| `APPROACH_STAGE*_DURATION_S` | 各段运动时间 | 过短可能导致 IK 不收敛 |

### 7.3 安全悬停避障（`USE_THREE_STAGE_APPROACH = False` 时生效）

| 参数 | 作用 | 调参方向 |
|------|------|----------|
| `SAFE_HOVER_BACK_M` | X 方向后撤距离 | 增大更安全，但可能超工作空间 |
| `SAFE_HOVER_Z_ABOVE_M` | 额外抬高量 | 增大可延长垂直行程 |
| `GRASP_DESCENT_DURATION` | 垂直下降时间 | 增大更平稳 |

### 7.4 视觉检测（Atlas 侧）

编辑 `config/vision.yaml`：

```yaml
vision:
  yolo:
    conf_threshold: 0.35   # 检测不到目标时适当降低
    iou_threshold: 0.45
```

### 7.5 支持的语音指令

语义解析（`vision_lim/semantic_parser.py`）当前支持：

| 类别 | 中文示例 | 输出 target |
|------|----------|-------------|
| 物体 | 瓶子、水瓶、杯、球、手机 | bottle / cup / ball / phone |
| 颜色 | 红、蓝、绿…（可选属性） | attribute: red / blue … |
| 动作 | 拿、取、抓 | action: fetch |
| 停止 | 停止、停下、取消 | action: stop |

ASR 同音纠错：如「屏子」自动纠正为「瓶子」。

## 8. 安全注意事项

1. **实机前必做 `--dry-coords`**，确认路径点在工作空间内、不会碰撞桌面物体。
2. **松爪流程**：系统默认「水平后撤后再松爪」，请勿在抓取点原位直接张开夹爪。
3. **急停**：操作前确认急停按钮可用，周围留出机械臂运动空间。
4. **段间停顿**：`APPROACH_STAGE_HOLD_S` 默认 2 s，便于观察；首次联调建议保持。
5. **单手策略**：`--hand left` 时左手 IK 运动 + `left_claw` 抓取，非抓取侧手臂保持待机位。

## 9. 故障排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| Atlas `import acl` 失败 | CANN 未 source 或 Python 版本不对 | 重新 `source scripts/activate_kuavi_atlas.sh` |
| 流水线报 ffmpeg 错误 | 未安装 ffmpeg | `sudo apt install ffmpeg` |
| YOLO 无检测结果 | 置信度太高 / 画面中无目标 | 降低 `conf_threshold`；确认 `yolov8n.om` 存在 |
| `yolo_backend: cpu` 而非 npu | acl 不可用或 `.om` 缺失 | 检查 NPU 环境与模型文件 |
| 深度值为 0 | 反光、超量程、color/depth 未对齐 | 重新采图；检查 depth 图对应像素 |
| 正上方 IK 失败 | 路径点超出工作空间 | 调小 `APPROACH_ABOVE_CLEARANCE_M`；脚本已拆「高位平移 + 下降」 |
| 抓取偏位 | 坐标变换或偏置不准 | 重新采图；调 `LEFT_GRASP_*_BIAS` |
| 松爪带倒物体 | 未走后撤流程 | 确认 `POST_GRASP_HORIZONTAL_RELEASE = True` |
| 下位机 import kuavo_sdk 失败 | 工作空间未 source | 设置 `KUAVO_WS_SETUP` 后使用 `run_grasp.sh` |
| 语音识别错误 | 环境噪声 / 同音字 | 使用 `--text` 跳过 ASR 单独测视觉；或重新录音 |

按顺序勾选，可快速定位问题环节：

- [ ] 上位机：`color_image.png` 与 `depth_image.png` 为同一场景

- [ ] Atlas：`source scripts/activate_kuavi_atlas.sh` 后 `import acl` 正常

- [ ] 下位机：`grasp_target.json` 与 `grasp_from_offline_vision.py` 在同一目录

## 11. 数据文件规范

### 11.1 `camera_info.txt` 格式

从 ROS 话题导出，需包含：

```
K: fx 0 cx 0 fy cy 0 0 1
```

### 11.2 `grasp_target.json` 关键字段

| 字段 | 类型 | 下位机是否使用 |
|------|------|----------------|
| `camera_coord_m` | `[x, y, z]` 米 | **是**（唯一必需） |
| `pixel_color` | `[u, v]` | 否（调试用） |
| `depth_m` | float | 否（调试用） |
| `voice_task` | object | 否（记录用） |

下位机脚本**仅依赖** `camera_coord_m`；无 JSON 时回退到脚本内 `CAMERA_POINT_M` 默认值。

### 11.3 目录结构（部署到 Atlas 后）

```
~/kuavi_robot_control/
├── instance/              # 输入数据 + 输出 JSON
├── ascend_models/         # .om 模型
├── config/                # asr / vision 配置
├── scripts/               # 流水线与抓取脚本
└── vision_lim/            # 语音视觉模块
```

## 13. 版本说明

本手册对应当前已验证闭环：

- **Atlas**：Whisper encoder NPU + YOLOv8n NPU，`atlas_voice_grasp_pipeline.py` 输出 `grasp_target.json`
- **下位机**：`grasp_from_offline_vision.py` 左手三段位姿抓取 + 安全放开 + 回零；非三段位姿时支持安全悬停避障路径

后续若改为 ROS 话题实时传图，上位机与 Atlas 之间可增加同步节点，**JSON 接口与下位机脚本保持不变**。
