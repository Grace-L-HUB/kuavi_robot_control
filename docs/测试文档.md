### 6.5 常见问题与判定

| 现象 | 可能原因 | 判定 |
|------|----------|------|
| import acl 失败 | CANN 未 source | TC-NPU-01 失败 |
| YOLO 无检测 | 无目标 / conf 过高 | 降 conf_threshold |
| bottle 未检出但 cup 有 | 检查 target_synonyms | 应通过 |
| 深度为 0 | 反光、未对齐 | 重采图 |
| IK 失败 | 超工作空间 | 调 APPROACH_* 参数 |
| 抓取偏位 | 偏置未调 | 调 LEFT_GRASP_*_BIAS |
